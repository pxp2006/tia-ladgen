## 绕开的 4 个工程障碍

### 1. DSH 工作区内 exe 被进程隔离
工作区里的 exe 只看到 22 个进程，看不到 TIA。放到 `D:\TiaLadGen\bin` + 交互式计划任务启动即可（379 进程）。

### 2. Openness 访问授权弹窗
每次新 exe 首连会弹 `Openness 访问`，三个自绘按钮无文本：左=是、中=全部选是、右=否。
`ClickFix.exe` 按 x 排序点中间按钮（授权并保存）。

`The action "Create block" only supports the programming language 'ProDiag'.`
→ **V21 只能通过 XML 导入创建 LAD 块**，没有对象模型直接建块的路。

### 4. 未编译/不一致的块不能导出

→ 想拿现成样本导出不行，必须自己构造 XML 导入（已做到）。

## V21 LAD 导入格式（实测通过，重要成果）

已验证可导入的最小结构（FC9001，LAD，一个常开→线圈网络）：

```xml
<Document>
  <Engineering version="V21" />
  <SW.Blocks.FC ID="0">
    <AttributeList>
      <Interface><Sections xmlns="http://www.siemens.com/automation/Openness/SW/Interface/v5">
        <Section Name="Input" /><Section Name="Output" /><Section Name="InOut" />
        <Section Name="Return" /><Section Name="Temp" /><Section Name="Constant" />
      </Sections></Interface>
      <MemoryLayout>Optimized</MemoryLayout>
      <Name>FC_GEN_TEST</Name>
      <Namespace></Namespace>          <!-- 必须有，否则 Missing 'Namespace' -->
      <Number>9001</Number>
      <ProgrammingLanguage>LAD</ProgrammingLanguage>
    </AttributeList>
    <ObjectList>
      <SW.Blocks.CompileUnit ID="1" CompositionName="CompileUnits">
        <AttributeList>
          <NetworkSource>
            <FlgNet xmlns="http://www.siemens.com/automation/Openness/SW/NetworkSource/FlgNet/v5">
              <Parts>
                <Access Scope="GlobalVariable" UId="21"><Symbol><Component Name="Tag_1"/></Symbol></Access>
                <Part Name="Contact" UId="22"/>
                <Part Name="Coil" UId="23"/>
                <Access Scope="GlobalVariable" UId="24"><Symbol><Component Name="Tag_2"/></Symbol></Access>
              </Parts>
              <Wires>
                <Wire UId="31"><Powerrail/><NameCon UId="22" Name="in"/></Wire>
                <Wire UId="32"><NameCon UId="22" Name="out"/><NameCon UId="23" Name="in"/></Wire>
                <Wire UId="33"><NameCon UId="22" Name="operand"/><IdentCon UId="21"/></Wire>
                <Wire UId="34"><NameCon UId="23" Name="operand"/><IdentCon UId="24"/></Wire>
                <Wire UId="35"><NameCon UId="23" Name="out"/><OpenCon UId="36"/></Wire>
              </Wires>
            </FlgNet>
          </NetworkSource>
          <ProgrammingLanguage>LAD</ProgrammingLanguage>
        </AttributeList>
        <ObjectList>   <!-- CompileUnit 必须有 ObjectList，否则 Cannot create CompileUnit -->
          <MultilingualText ID="41" CompositionName="Title">
            <ObjectList><MultilingualTextItem ID="42" CompositionName="Items">
              <AttributeList><Culture>zh-CN</Culture><Text>Gen Test</Text></AttributeList>
            </MultilingualTextItem></ObjectList>
          </MultilingualText>
          <MultilingualText ID="43" CompositionName="Comment">
            <ObjectList><MultilingualTextItem ID="44" CompositionName="Items">
              <AttributeList><Culture>zh-CN</Culture><Text></Text></AttributeList>
            </MultilingualTextItem></ObjectList>
          </MultilingualText>
        </ObjectList>
      </SW.Blocks.CompileUnit>
    </ObjectList>
  </SW.Blocks.FC>
</Document>
```

关键约束（踩出来的）：

- `<Namespace></Namespace>` 必须有无；否则 `Missing 'Namespace' identifier attribute`
- CompileUnit 的 `ObjectList` + Title/Comment 必须有无；否则 `Cannot create the 'SW.Blocks.CompileUnit' object`
- 文本 culture 必须用项目语言（该项目是 `zh-CN`，`en-US` 报 `culture does not exist within the current project`）
- FlgNet 命名空间 `.../NetworkSource/FlgNet/v5`
- 操作数用符号访问 `<Access Scope="GlobalVariable"><Symbol><Component Name="..."/></Symbol></Access>` 可导入
- 绝对地址写法 `<Access Scope="Address"><Address Area="Input" Width="Bit" BitOffset="0"/></Access>` **尚未导入成功**（下一步）
- 空网络（Parts 为空）不允许；必须至少一个 Part

### 块结构

| 块 | 编号 | 内容 |
|---|---|---|
| `Main` (OB1) | 1 | LAD，一个网络：调用 FB_GEN_MAIN / FB_GEN_MAIN_DB |
| `FB_GEN_MAIN` | 9100 | LAD，34 个网络：12 步顺序 + 10 个 TON + 输出 + 复位 + 上层连续设备 |
| `FB_GEN_MAIN_DB` | 9101 | 实例 DB（用 `CreateInstanceDB(name,false,9101,"FB_GEN_MAIN")` 建） |
| `LADGEN_Tags` | — | 22 个变量（M10.x 操作按钮、M12.x 上层设备、M20/M21.x 各轴使能/位置状态、MD10/14/18 定时） |

### 逻辑要点

- 步标志 `Step_0..Step_10` 存在 FB 静态区；每步一个 `Timer_i`(TON_TIME)
- 转移：`Step_i AND Done_i → S Step_{i+1} / R Step_i`
- 输出：`Step_i → Coil/Negated Coil` 驱动各轴"使能/位置状态"位
- 第 10 步结束：连续模式 → 回步 1；否则回步 0
- 复位按钮：链式 R 所有步 + S Step_0
- 上层连续设备：`启动按钮 AND NOT 复位按钮 → 主动轮/切割/链结 使能`

### 生成方式

`tools/gen_main.py` 生成 `gen_main.xml` → `TiaProbe.exe --import`（导入+编译）

### 已验证的 LAD XML 元素（V21）

Contact / Negated Contact / Coil / SCoil / RCoil / TON(多实例,`TON_TIME`,TemplateValue `time_type` Type=Type `Time`) / Access(GlobalVariable, LocalVariable) / Wire(Powerrail,NameCon,IdentCon,OpenCon) / Call(CallInfo Name+BlockType+Instance)

### 已知限制

- 参数层（把位置/速度写入驱动器寄存器）未实现 —— 需用户提供轴通讯映射；当前只驱动"使能/位置状态"逻辑位（与用户公式表一致）
- 定时器为多实例 FB 定时器；`PT` 用全局 Time 变量（MD10/14/18），改时间是改这三个变量
- 项目目前处于未保存状态；`Main` 已被替换为调用主程序的网络

### 关键 XML 经验（新增）

- FB 静态变量带初值：`<Member Name="T_Feed" Datatype="Time"><StartValue>T#15s</StartValue></Member>`
  （`StartValue` 是**子元素**，不是属性；写成属性会报 "未声明 StartValue 特性"）
- 时间常量不能直接作为 TON 的 PT `LiteralConstant`（TIA 拒绝 "15s"/"T#15S"/"15000" 等写法）→ 用静态变量
- 同一变量多个线圈（跨网络）合法，编译 0 错
- 变量名不能与项目里已有变量重名（即使在不同变量表）→ 本程序变量加 `V3_` 前缀
- 在线状态不能导入块：`This function is not supported in online mode` → 先用 `OnlineProvider.GoOffline()`

### 变量

`LADGEN_Tags` 内 19 个 `V3_` 前缀变量，地址与 `01_变量表.xlsx` 完全一致：
V3_启动按钮 %I0.0、V3_急停 %I0.1、V3_复位按钮 %I0.2、
V3_上层使能 %Q0.0 … V3_撑袋器位置状态 %Q1.7
