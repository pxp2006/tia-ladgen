# 时间参数表（装袋机主程序 FB_GEN_MAIN）

> 修改位置二选一：
> 1. **离线改默认值**：TIA → `FB_GEN_MAIN` → 接口 → Input → 改 `T_xxx` 的“起始值” → 编译下载（下载时可选是否重新初始化 DB）
> 2. **在线微调（推荐）**：TIA → `FB_GEN_MAIN_DB` → 监控 → 直接改“监视值”里的当前值 → 下一个定时器周期立即生效，**不用下载**

| 步 | 变量名 | 默认值 | 含义 | 说明 |
|---|---|---|---|---|
| 1 | `T_Feed` | `T#15s` | 上料堆积 | 上层一直转，等料堆够 |
| 2 | `T_NozzleDown` | `T#2s` | 吸嘴下行 | 吸嘴转一圈=上下往复一次 |
| 3 | `T_NozzleUp` | `T#2s` | 吸嘴回上 | 吸住袋口 |
| 4 | `T_BagOpen` | `T#2s` | 撑袋器张开 | |
| 5 | `T_ScrewDown` | `T#8s` | 平台降到最低 | **从步 2 开始累计**（用 `In5` 位把步2~5 或起来） |
| 6 | `T_FeedFwd` | `T#3s` | 送料前伸 | 平台送到袋口下方 |
| 7 | `T_Load` | `T#5s` | 人工装袋 | 纯计时，机器不知道人放完没有 |
| 8 | `T_FeedBack` | `T#3s` | 送料收回 | 先收料 |
| 9 | `T_Wait` | `T#3s` | 等待 | |
| 10 | `T_ScrewUp` | `T#8s` | 平台上升 | |
| 11 | `T_Baffle` | `T#2s` | 挡板释放 | 物料落到平台 |
| — | `T_Heart` | `T#1s` | 心跳周期 | 驱动 `M32.0` 翻转，仅调试用 |

整轮默认约 **53 秒**。

## 注意

- 时间值是 **FB 的 Input 参数**，所以既能在块接口里改，也能在实例 DB 里在线改。
- 如果下载后 DB 当前值仍是 0（之前没初始化过），可以：
  - 重新下载并选择“全部/初始化数据块”，或
  - 打开 `FB_GEN_MAIN_DB` 在线把这 11 个值改成上表的值
- `PT` 在扫描周期读取，在线改值后**当前这一步不会立即变**，从下一步开始生效。

## 位置状态（跟随步号，不需要调）

| 输出 | 地址 | 规则 |
|---|---|---|
| 挡板位置状态 | M30.5 | 步2~10 = 1（截留），其余 = 0（释放） |
| 丝杆位置状态 | M30.7 | 步2~9 = 0（下降），其余 = 1（上升） |
| 送料1/2 位置状态 | M31.1 / M31.3 | 步6、7 = 0（前伸），其余 = 1（收回） |
| 吸嘴位置状态 | M31.5 | 步2 = 0（下行），其余 = 1（在上） |
| 撑袋器位置状态 | M31.7 | 步4~11 = 1（张开），其余 = 0 |

极性如果现场反了，改生成脚本 `pos_values()` 里的布尔值即可（或把 MCD 侧信号反接）。

## 按钮

| 按钮 | 地址 | 作用 |
|---|---|---|
| 启动 | `V3M_启动按钮 %I0.0` | 置位 `Run`，从步1 开始循环 |
| 急停 | `V3M_急停 %I0.1` | 复位 `Run` + 清所有步 + 关所有使能（**安全回路必须硬件做**） |
| 复位 | `V3M_复位按钮 %I0.2` | 同上，但复位时**保持使能**（让机构能回初始位） |

`DebugAutoRun`（FB 静态，默认 **false**）：置 true 后上电自动运行，不需要按启动按钮，调试用。
