## 2. 让它跑起来（仿真或真机）

### 2.1 编译
右键 `PLC_1` → “编译” → “硬件和软件（完全重建）”，或 `Ctrl+B`。

> 会有一条**警告**：`Inputs or outputs are used that do not exist in the configured hardware.`
> 原因是这个测试项目的 CPU 是 **1212C（只有 Q0.0~Q0.5）**，程序用到 Q1.0~Q1.7。
> 逻辑没错，警告不影响仿真；换到真机 CPU（或加 DI/DQ 信号板）就消失。

### 2.2 下载
- **只有 PLCSIM**：菜单“在线”→“仿真”→“启动仿真” → 再“下载到设备”
- **真机**：设置好 CPU IP → “下载到设备” → 下载完成后“转至在线”

### 2.3 第一次运行时
- 上电默认 `Run=0`、所有步=0 → 机构停在“初始位”：挡板释放、丝杆上升、送料收回、吸嘴在上、撑袋不撑开
- **注意**：此时 `EnAll=0`，所以机构不会动（这是正常的，只有启动或复位时给使能）

## 3. 怎么调试（重点）

### 3.1 在线监控块
打开 `FB_GEN_MAIN` → 点工具栏的 **“监控”**（眼镜图标）→ 网络里绿色表示导通。

### 3.2 看步号
- 打开 `FB_GEN_MAIN_DB` → 监控 → 看 `Step_1`…`Step_11` 哪一个为 TRUE
- 也可以看 `Timer_x.ElapsedTime` 判断当前步还剩多久

### 3.3 手动跑一遍（没有实物按钮时）
建一个监控表（“监控与强制” → 新建监控表），加入：

```
V3_启动按钮      %I0.0
V3_急停          %I0.1
V3_复位按钮      %I0.2
V3_上层使能      %Q0.0     ... 其余使能/位置状态
```

然后：
1. 强制 `V3_启动按钮 = 1` 一秒再取消 → `Run` 置位，`Step_1` 亮
2. 等 15 s（T_Feed）→ 自动到 `Step_2`，同时 `丝杆位置状态=0`、`挡板位置状态=1`、`吸嘴位置状态=0`
3. 依次 2s→2s→1s→…→步11→回步1
4. 强制 `V3_复位按钮=1` → 所有步清零，回到初始位（此时使能仍为 1，机构能动）

### 3.4 接 MCD 数字孪生体

## 4. 改参数

## 5. 搬到你的真机项目

当前程序放在 `opc连接` 这个**测试项目**里（CPU 只有 6 个 DQ）。真机项目显然不是这个。

正确做法：
1. 保存并**关闭**当前项目（TIA 同一个版本只能开一个项目）
2. 打开真机项目
3. 把 `01_变量表.xlsx` 导入（PLC 变量 → 默认变量表 → 右键“导入”），得到 19 个**不带前缀**的变量
4. 我按“不带前缀”的变量名重新生成一份 `FB_GEN_MAIN.xml`，你在真机项目里：
   程序块 → 右键 → “从外部源文件导入”/“打开 XML” → 导入 FB
5. OB1 里把 FB 拖进去，生成实例 DB，编译

> 为什么现在带 `V3_` 前缀：这个测试项目里之前已经建过同名变量，TIA 变量名全项目唯一，重名会报错。
> 真机项目里没有这个问题，可以直接用原名。

## 6. 已知限制（和 v3 说明书一致）

- **没有到位反馈**，纯时间推进：料堆够不够、人装完没有、机构到没到位，程序都不知道
- **没有报警**、没有步超时、没有手动单步模式
- **急停只把使能清零**（机构靠惯性/抱闸停），**安全回路必须硬件做**
- 循环是连续的（步11 结束自动回步1），没有“单次”模式
- 撑袋器在下一周期（步4）才张开，步1 是闭合状态
